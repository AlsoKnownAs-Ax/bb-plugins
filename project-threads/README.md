# Project Threads

Replaces bb's sidebar thread list:

- **Working** — threads that are running. When one finishes it stays here
  labelled **Ready** (or **Failed**); click the ✓ button to move it back to
  its project.
- **One collapsible section per project** for everything else. Collapsed
  state is remembered per client. Hover a project header for a "+" new-thread
  button.

If another thread list is active, pick this one under
Settings → Appearance → Sidebar.
